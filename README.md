## 一、选海外 VPS，先看这四件事

### 线路：机房位置只是起点

香港机房和美国机房的距离差不代表实际体验差。同样是“香港”，走 CN2 GIA 精品线路和走普通 BGP 优化线路，国内访问延迟能差出一截；同样是洛杉矶，回程走 AS9929、走 4837、走 CN2 GIA，晚高峰的表现是三回事。

常见几条线路的定位，用一句话区分：

- **AS9929**：联通精品网，三网回程优化，晚高峰稳定，价格贵一些，适合直播、长时间在线的账号运营
- **4837（CUVIP）**：大陆优化但带宽给得大方，适合大流量、下载、采集这类不看单线程延迟的场景
- **CN2 GIA**：电信联通回程优化，建站首选，带防御的版本更抗打
- **CMI / CU2**：香港方向，国内三网直连，延迟最低

### IP 属性：机房 IP、原生 IP、双 ISP 住宅 IP 不是一回事

这是很多人踩坑的地方。普通数据中心 IP，平台一查 ASN 就知道是机房段，TikTok 限流、Netflix 提示“使用了代理”、亚马逊账号被关联，问题往往不出在网速上。

三者的区别大致是：

- **机房 IP**：来自云服务商或数据中心 ASN，最便宜，风控识别率最高
- **原生 IP**：IP 段注册地和机房所在地一致，纯净度比普通机房 IP 好，但仍然是机房属性
- **双 ISP 住宅 IP**：IP 段来自真实的家庭宽带运营商，在各大 IP 数据库里被识别为运营商住宅用户

跑平台账号的业务，第三类才是刚需。这也解释了为什么同价位下，有些套餐带宽小、流量少，价格却一样。

### 机房位置要和你的运营商对得上

新加坡、英国、台湾这类节点，对国内不一定是三网优化。公开的产品说明里就写得很直白：新加坡“联通和部分移动直连速度不错，电信用户建议配合香港或日本中转”；英国“非大陆优化线路，建议配合香港或日本节点中转”。买之前先想清楚自己用什么宽带，不然买回来还要再搭一台中转，成本翻倍。

### 计费周期与退款：决定你能不能不后悔

年付折合月价通常比月付低，但代价是锁一年。真正要看的不是折扣百分比，而是“万一不合适，我能不能退”。丽萨主机这条给得比较干脆：**48 小时不满意无条件退款，原路返回，不需要解释原因**，政策直接显示在控制面板里。对新用户来说，这比任何折扣都实在——先月付跑两周，或者年付但留好 48 小时窗口做基础测试，都是可行的路径。

## 十一、几个常被问到的问题

**月付还是年付？**
新用户先月付跑两到四周，确认线路速度、IP 在目标平台的表现都符合预期，再转年付。年付确实便宜，但锁一年，而且部分年付款的月流量比同价位月付款低（比如 ¥499 年付给 600GB，¥68 月付给 1000GB）。

**流量跑完会怎样？**
产品页没有明示超限后的处理方式——是断网还是降速，官方没有公开写。下单前用在线客服问清楚，比自己猜要省事。

**电信、联通、移动，哪个机房最快？**
香港 CMI / CU2 / CN2 三网都有优化，延迟最低，对速度敏感的场景优先。美国 9929 三网回程优化，国内访问稳定，第三方测评记录的洛杉矶三网平均延迟约 172ms。新加坡、台湾、英国属于非大陆优化，建议搭配香港或日本中转。

**能装 Windows 吗？**
美国 9929 精品网络的 VPS 支持安装 Windows，其他产品线以购买时的产品说明为准。

**IP 被封了怎么办？**
提交工单申请更换，部分年付套餐支持免费更换。先排除本地网络问题再申请。

**支持哪些付款方式？**
支付宝、微信支付、信用卡。

**机器是什么架构？**
全线 KVM，NVMe 固态硬盘。
